## Project Overview
This repository contains a training and practice board designed as part of the **The Life Cycle of an Electronic Board**. 

The primary goal of this project was not to build a commercial end-product, but rather to establish a strong foundational understanding of PCB layout techniques, component placement strategies, and EDA tool workflows. It serves as a hands-on milestone in my continuous hardware engineering education.

## Key Learning Outcomes & Lessons Learned
Rather than just following instructions, this project served as a sandbox to experiment and learn from practical design challenges. Throughout the design process, I focused on mastering:
*   **Routing Fundamentals:** Gained practical experience with trace width calculations, clearance rules, and signal flow optimization.
*   **Component Placement:** Learned how to logically group sub-circuits (like keeping decoupling capacitors close to MCU power pins) to minimize noise and loop areas.

*Note: As an educational prototype, this board represents my initial learning curve in hardware design. Any identified routing sub-optimizations or placement iterations are being documented as case studies to improve my future, more complex mixed-signal designs (such as my 4-layer TDOA project).*
